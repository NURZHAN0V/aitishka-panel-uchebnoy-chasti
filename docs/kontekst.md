# Контекст

Клиент **«Панель учебной части»** — часть экосистемы IT Camp Sochi (школа при Гимназии №16).

Сотрудники учебной части управляют студентами, преподавателями, группами, расписанием, финансами, маркетом и модерацией.

Студенты работают в **электронном дневнике**, преподаватели — в **кабинете преподавателя**. Учётные записи сотрудников создаёт системный администратор.
