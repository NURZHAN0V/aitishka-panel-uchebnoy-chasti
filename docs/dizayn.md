# Дизайн

Палитра и UI-kit совпадают с электронным дневником и кабинетом преподавателя.

## Цвета

| Назначение | Значение |
| --- | --- |
| Primary | `#8B5CF6` |
| Success | `#10B981` |
| Warning | `#F59E0B` |
| Error | `#EF4444` |
| Page bg | `#F5F7FA` |
| Card | `#FFFFFF` |

Токены: `src/assets/styles/_tokens.scss`. Шрифты: Nunito (UI), Marmelad (display).

## Скругления

Карточки `$radius-card` (20px), кнопки/чипы 12px. Без pill-таблеток.

## Иконки

Только локальные **Hugeicons SVG** через `BaseIcon`. Иллюстрации AVIF не используются.

## Шапка

Приветствие на главной; на остальных экранах — хлебные крошки.
